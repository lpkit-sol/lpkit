# @lpkit-sol/lpkit

Umbrella package that re-exports every lpkit package. See the [main README](https://github.com/lpkit-sol/lpkit#readme).

> Independent, unofficial project. Not affiliated with Meteora.

**Pre-alpha (0.x).** The API may change.

```bash
npm install @lpkit-sol/lpkit @meteora-ag/cp-amm-sdk @coral-xyz/anchor@^0.31 @solana/web3.js@^1 @solana/spl-token@^0.4
```

```ts
import { fetchPoolClassification, fetchPublicFeePresets } from "@lpkit-sol/lpkit";
```
