# lpkit dashboard

A free, read-only web page built on lpkit. Paste a Meteora DAMM v2 pool, a token mint, or a wallet or position, and read it in plain language, or browse every public fee preset.

> Independent, unofficial project. Not affiliated with Meteora. Not financial advice.

- **No server, no keys.** The page is static. Your browser queries a Solana RPC directly (by default the free PublicNode endpoint, `solana-rpc.publicnode.com`, because `api.mainnet-beta.solana.com` rejects browser requests). You can paste your own RPC; it is kept only in your browser.
- **Fee presets** come from a static `presets.json` regenerated by CI every day, so the browser never runs `getProgramAccounts`.
- **Positions:** a position address works on the default RPC. A wallet lookup needs `getTokenAccountsByOwner`, which free public RPCs refuse, so it needs your own RPC. Vesting schedules need `getProgramAccounts`; without it the page still shows the rest.
- Deep links: `?pool=<address>`, `?token=<mint>` and `?positions=<wallet or position>`.

## Run locally

From the repository root:

```bash
npm install
npm run build
npm run build:presets -w @lpkit-sol/dashboard
npm run dev -w @lpkit-sol/dashboard
```

Deployed to GitHub Pages by `.github/workflows/pages.yml`.
