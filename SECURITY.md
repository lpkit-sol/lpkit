# Security policy

lpkit only reads public on-chain data and never asks for private keys. Still, a bug could make a tool built on it misread a pool or build a wrong instruction.

## Reporting a vulnerability

Please report it privately through [GitHub private vulnerability reporting](https://github.com/lpkit-sol/lpkit/security/advisories/new). Do not open a public issue.

Include the package and version, what you expected, what happened, and a pool or account address that reproduces it if you have one. **Never send private keys, seed phrases or RPC URLs with tokens.**

## Supported versions

lpkit is pre-alpha (0.x). Only the latest published version receives fixes.
